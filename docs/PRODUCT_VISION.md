# 제품 비전

## 한 문장

사용자가 자기 컴퓨터에서 **AI 회사를 설계·운영**하고, 실제 Claude Code 에이전트들에게 일을 맡기는 로컬 퍼스트 플랫폼.

## 무엇이 아닌가

- 단순 AI 채팅 앱이 아니다: 대화 상대는 직책·부서·권한을 가진 조직 구성원이다.
- 워크플로 빌더가 아니다: 노드 그래프가 아니라 사람이 이해하는 조직(보고 관계·협업 관계)을 설계한다.
- 자체 LLM 에이전트 프레임워크가 아니다: 실행은 사용자가 설치한 Claude Code가 하고, 이 플랫폼은 조직·권한·흐름을 관리한다.

## 사용자와 대표 장면

| 사용자 | 장면 |
|---|---|
| 대학원생·연구원 | 연구 조직 템플릿으로 시작 → 문헌 조사 에이전트에게 논문 정리를 맡기고 PDF를 첨부 |
| 개인 개발자 | 개발 조직을 만들고 저장소를 프로젝트로 연결 → CEO에게 기능 요청 → 셸·파일 수정은 승인하며 진행 |
| 1인 창업자 | "시장 조사·사업성 검증·마케팅 조직을 만들어 줘" → 대화로 조직을 다듬고 생성 |

## 핵심 가치(설계 판단 기준)

1. **쉬운 시작**: 템플릿 또는 대화로 1분 안에 조직을 만든다.
2. **자유로운 설계**: 부서·직책·에이전트 수에 제한이 없고 언제든 고친다(변경 이력과 되돌리기).
3. **실제 업무**: 에이전트는 실제 Claude Code로 파일을 읽고 고치고 명령을 실행한다.
4. **협업과 위임**: 조직도와 별도로 협업 관계를 정의하고, 업무를 위임한다(자동 분배는 Phase 5).
5. **Claude Code 활용**: Skills·MCP·Plugins·Hooks·세션 기능을 공식 인터페이스로 쓴다.
6. **통제**: 에이전트마다 권한을 좁히고 위험한 작업은 사람이 승인한다.
7. **가시성**: 조직도·실행 패널·사무실에서 누가 무엇을 하는지 실시간으로 본다.
8. **로컬 퍼스트**: 유료 서버 없이 이 컴퓨터에서 실행한다.

## 설계 모드와 운영 모드

- **설계 모드(조직 설계)**: 템플릿·설계 담당 Claude·조직도 편집으로 조직 명세를 만들고 검토 후 적용한다.
- **운영 모드(커맨드 센터·조직·사무실)**: 적용된 조직의 에이전트가 일한다.

설계 담당 Claude와 조직 CEO 에이전트는 역할·세션·권한이 분리된 별개의 실행이다.
