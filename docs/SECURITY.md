# 보안

이 앱은 사용자의 파일과 Claude Code를 다룬다. 로컬 프로그램이라도 보안을 생략하지 않는다.

## 1. 로컬 서버 노출 방지

- 백엔드는 루프백에만 바인딩한다(`AI_ORG_HOST`가 루프백이 아니면 시작 거부). 웹 개발 서버도 `127.0.0.1`.
- `LocalOnlyMiddleware`
  - **Host 허용 목록**(127.0.0.1·localhost·[::1]) — DNS 리바인딩 차단.
  - **Origin 허용 목록**(:3000·:8000) — 다른 웹사이트에서 온 요청(CSRF) 차단. WebSocket도 같은 검사(4403).
  - 상태 변경 요청은 JSON만(업로드 경로만 multipart) — 단순 폼 CSRF 차단.
  - `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`.
- 한계: 같은 컴퓨터의 다른 프로세스·다른 OS 사용자는 API를 호출할 수 있다 → §7 로그인 설계.

## 2. 파일 접근

- 프로젝트: 등록된 탐색 경로 안의 실제 경로만. 심볼릭 링크 해석. 루트 등록 금지. 등록 해제는 파일을 지우지 않는다.
- 에이전트 도구: `file_path`·`notebook_path`·`path` 입력이 작업 폴더·첨부 폴더 밖이면 **거부**(읽기 포함).
- 컨텍스트 경로: 대화의 프로젝트 안만, 저장·전송 때마다 검증.
- 셸 명령: 인자 중 절대 경로·`~`·`..` 경로가 작업 폴더·첨부 폴더 밖을 가리키면 승인 설정과 관계없이 **사용자 승인**을 받는다
  (명령 이름 자리의 실행 파일과 `/dev/null` 등 장치 파일 제외). 삭제 명령이 범위 밖을 가리키면 삭제가 허용된 에이전트도 승인을 받는다.
  승인 요청에는 이유("작업 폴더 밖 경로를 참조합니다: …")가 함께 보인다.
- **한계**: 변수 확장(`$HOME/...`), 명령 치환, 스크립트 파일 내부의 경로는 정적으로 알 수 없다. 셸 허용 에이전트는 셸 승인(기본값)을 유지하는 것을 권장한다.

## 3. 에이전트 권한

- `AgentPermissions`: 셸·파일 쓰기·삭제·네트워크·위임 허용, 승인 필요 묶음(shell·file_write·file_delete·network·delegate·mcp), 권한 모드(default·plan·acceptEdits). `bypassPermissions`는 스키마에서 거부.
- 기본값(보수적): 셸 금지, 삭제 금지, 위임 금지(CEO 제외), 셸·파일 쓰기·삭제·MCP 도구는 승인 필요.
- 집행 순서: ① 금지 묶음은 `disallowed_tools`(Claude Code deny — 어떤 모드에서도 우선) ② 모든 도구 호출 PreToolUse 훅에서 정책 판정
  ③ Claude Code 자체 확인 요청은 `can_use_tool`. 우리 정책은 Claude Code 권한을 좁히기만 하며 우회하지 않는다.
- `setting_sources=["project"]`: 사용자 전역 설정의 allow 규칙이 앱 승인을 건너뛰지 않게 한다.
- 권한 상속 없음: 각 실행은 그 에이전트 자신의 정책만 쓴다. 위임 기능(Phase 5)도 위임받은 에이전트의 정책으로 실행한다.
- AI(설계 담당)의 권한 확대 제안은 사용자가 명시적으로 수락해야 적용된다. 허용 목록(Skills·MCP)은 AI가 바꿀 수 없다.

## 4. 명령 실행 승인

승인 요청에는 에이전트, 도구, 대상(명령·경로, 최대 300자)이 보인다. 시간 제한(기본 900초) 후·실행 종료·중지 시 거부/만료.
승인·거부는 DB(`approvals`)와 활동 기록에 남는다.

## 5. 민감 정보

- 이 앱은 Claude 자격증명·API 키를 읽거나 저장하지 않는다.
- MCP 설정의 env·헤더·인자·URL 쿼리 값은 응답에 넣지 않는다. 허용된 서버의 원본 설정(비밀 포함)은 실행 옵션으로만 Claude Code에
  전달하고 DB·로그·화면에 남기지 않는다(테스트 `test_run_request_carries_allowed_mcp_and_plugins`). Git 원격 URL의 자격증명은 지운다.
- 실행 기록에는 도구 이름과 짧은 대상만 저장한다(도구 출력 원문 저장 안 함). 대화 본문과 응답은 로컬 DB에 저장된다.
- 데이터 폴더 `~/.ai-org`는 0700, 첨부 파일은 0600.

## 6. 업로드

확장자 허용 목록, 매직 바이트 검사, UTF-8 텍스트 검사, 20MB·10개 제한, 파일 이름 정리, 초안 24시간 후 정리, 대화 삭제 시 삭제.
첨부는 실행 시 읽기 허용 폴더(add_dirs)로만 노출된다.

## 7. 인증·사용자 관리(설계, Planned)

현재는 **로컬 단일 사용자 모드**다(§1의 네트워크 경계가 보호). 다음 단계 설계:

| 항목 | 설계 |
|---|---|
| 로컬 계정 | 첫 실행 시 관리자 계정 생성. 비밀번호는 argon2id 해시(평문 저장 금지) |
| 세션 | HttpOnly·SameSite=Strict 쿠키, 서버 측 세션 테이블(토큰은 해시로 저장), 만료·로그아웃 |
| 분리 | `AuthProvider` 인터페이스(local·oauth)로 앱 인증을 분리. **앱 로그인과 Claude Code 인증은 별개** — Claude Code는 CLI 로그인을 그대로 쓴다 |
| 다중 사용자 | `users`·`memberships(user, organization, role)` 추가, 조직·프로젝트·대화 조회에 소유 범위 적용, 사용자별 대화 기록 |
| OAuth | GitHub/Google 확장 지점(Agent Office의 OAuth 흐름 참고, 상태값·PKCE) |
| 사용자 설정 | 테마·기본 조직·알림 |

## 8. 안정성

비정상 종료 시 시작할 때 진행 중 상태를 정리한다. 동시 실행 수 제한. 같은 세션 동시 resume 금지. 실행 중 조직 변경은 확인 후 적용.

## 9. 취약점 제보

공개 저장소의 Issue가 아니라 GitHub Security Advisory(비공개 제보)를 사용한다.
