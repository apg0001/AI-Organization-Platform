# ADR-005: 오케스트레이션 — 자체 조직 엔진, Agent Teams 미사용

- 날짜: 2026-11-25 · 상태: 채택(Phase 5에서 구체화)

## 배경
CEO → 부서장 → 담당자 위임, 보고, 검토가 필요하다. 조직도는 사용자가 설계한다.

## 대안
1. Claude Code Agent Teams 2. CEO 세션 안의 Claude Code 하위 에이전트(Agent 도구)로 모두 처리 3. 자체 오케스트레이터 + 에이전트별 독립 세션

## 결정
에이전트마다 독립 Claude Code 세션을 두고, 위임·보고는 플랫폼의 작업(Task) 모델과 인프로세스 MCP 도구(`delegate_task` 등)로 구현한다.
Claude Code 하위 에이전트는 한 에이전트 안의 보조 수단으로만 허용(위임 권한이 있을 때).

## 이유
에이전트마다 권한·작업 폴더·Skills를 따로 줘야 하는데 Agent Teams·하위 에이전트는 이를 조직 단위로 분리하기 어렵다.
작업 기록·승인·사무실 시각화는 플랫폼이 사실 상태를 가져야 가능하다.

## 영향
+ 조직 설계와 실행이 명확히 분리. − 위임 스케줄러·보고 흐름을 직접 구현해야 함(Phase 5).
