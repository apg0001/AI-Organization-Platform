# ADR-007: 실시간 통신 — 단일 WebSocket + 프로세스 내 이벤트 버스

- 날짜: 2026-11-25 · 상태: 채택

## 대안
1. 메시지별 SSE 스트림 2. WebSocket 하나로 모든 이벤트 3. 폴링(Agent Office는 DB 폴링 기반 WS)

## 결정
`/api/v1/ws` 하나로 서버 → 클라이언트 이벤트를 보낸다. 백엔드는 asyncio 큐 기반 `EventBus`. 클라이언트는 이벤트로 화면을 갱신하거나
TanStack Query 캐시를 무효화하고, 재연결 시 전체를 다시 받는다. 스트리밍 텍스트는 저장하지 않고 완료본만 저장한다.

## 이유
여러 대화·에이전트·승인·설계 이벤트를 한 연결로 받는 게 단순하다. 단일 프로세스라 외부 브로커가 필요 없다.

## 영향
+ 단순. − 느린 구독자는 이벤트를 잃을 수 있음(재연결 시 재조회로 보완). − 다중 프로세스 확장 시 브로커 필요.
