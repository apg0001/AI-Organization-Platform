# ADR-008: 조직 설계 — 단일 명세(OrgSpec) 초안과 적용·이력

- 날짜: 2026-11-25 · 상태: 채택

## 배경
템플릿·AI 대화·조직도 직접 편집이 같은 조직을 다루며 서로 어긋나면 안 된다. AI 제안은 사용자 승인 없이 확정되면 안 된다.

## 대안
1. 실제 조직 테이블을 바로 수정(대화·편집 모두) 2. 대화 기록에서 매번 조직을 재생성 3. 명세 초안(단일 상태) → 검토 → 적용

## 결정
모든 생성·수정은 `OrgDesign.spec`(OrgSpec)을 바꾸고, 사용자가 적용해야 실제 조직에 반영한다. 적용마다 `OrgRevision` 스냅샷.
AI 출력은 JSON 스키마 구조화 출력 → 서버 검증 → 권한 확대·허용 목록 변경을 격리(`sanitize_proposal`). 템플릿도 같은 OrgSpec 파일.

## 영향
+ 미리보기·검토·되돌리기가 자연스럽다. + 템플릿별 구현 없음. − 설계 중 변경과 실행 중 조직 사이 차이를 사용자가 인지해야 함(UI에서 명시).
