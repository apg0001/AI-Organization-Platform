# ADR-003: 데이터베이스 — SQLite(로컬 파일)

- 날짜: 2026-11-25 · 상태: 채택

## 배경
단일 사용자 로컬 앱. 외부 서버를 요구하지 않아야 한다. Agent Office는 PostgreSQL을 쓴다.

## 대안
1. SQLite 2. PostgreSQL(Docker) 3. JSON 파일

## 결정
SQLite(`~/.ai-org/ai-org.db`, WAL, 외래 키). 정책처럼 형태가 바뀌는 값만 JSON 열.
0.0.x는 시작 시 `create_all`. **다음 스키마 변경 전에 Alembic을 도입한다.**

## 이유
설치 없음, 백업은 파일 복사, 단일 작성자에 충분. 관계·제약(순환 방지는 앱에서)이 필요해 JSON 파일은 부적합.

## 영향
+ 제로 설정. − 마이그레이션 도입 전 스키마 변경은 DB 재생성 필요. − 동시 쓰기 한계(단일 프로세스라 문제 없음).
