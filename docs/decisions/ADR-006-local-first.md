# ADR-006: 로컬 퍼스트, 루프백 전용

- 날짜: 2026-11-25 · 상태: 채택

## 배경
사용자 파일과 Claude Code를 다루며 유료 서버를 요구하지 않아야 한다.

## 결정
백엔드는 루프백에만 바인딩(그 외 주소면 시작 거부), Host·Origin 허용 목록, 브라우저는 파일 시스템에 직접 접근하지 않음.
데이터는 `~/.ai-org`. 원격 노출·클라우드 동기화는 범위 밖. 데스크톱 패키징은 Tauri 검토(DEPLOYMENT.md).

## 영향
+ 비용·개인정보 위험 최소. − 같은 컴퓨터의 다른 사용자·프로세스에 대한 보호는 로그인 도입(SECURITY.md §7) 전까지 제한적.
